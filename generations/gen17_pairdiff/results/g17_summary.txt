Gen17 lead probe -- within-publication pairwise difference learning (PADRE / DeepDelta)
Run 2026-09-09 on the gen14 cached bench (gen14_direction/cache/bench.pkl), well-determined
cells only (n_metals >= 5, 289 of 521).  All numbers below are leave-one-publication-out
(LOPO) on that subset, NOT the project's BP protocol with 5 seeds and the chemotype-blocked
bootstrap, so they are indicative, not headline.

   4296 ordered within-publication pairs (2148 unordered).  One publication supplies
   34.5 % of all pairs, so every interval below resamples publications, not pairs.

   same extractant, conditions differ      2264         0.1902

2. NOISE FLOOR
   median replicate sd of log D              0.333
   propagated sd(a) per cell                 0.115
   |delta a| expected from replicate noise    0.130
   -> the "same extractant / conditions differ" (0.190) and "diff extractant / same
      conditions" (0.250) strata carry real signal above the floor; the third does not.

4. THE CLEANEST CONTRAST IN THE CORPUS -- also a null.
   Same publication, IDENTICAL 72-column condition vector, DIFFERENT extractant:

   TOPOi|TOPOj    ET    0.1912  (+0.0082)      TOPOi|TOPOj    ridge 0.2387  (+0.0556)
   dDONORS13      ET    0.2178  (+0.0348)      dDONORS13      ridge 0.2103  (+0.0272)

   With the lab effect AND the condition effect cancelled exactly by construction, the
   amplitude difference between two ligands measured side by side is still not a
   function of the donor topology or the donor census.

5. SIDE RESULT -- the sibling ANCHOR, which needs no model at all.
   Extractant-macro MAE of log SF on the same subset (indicative scale: this subset's
   zero-curve arm is 0.543 where the project's BP mean-curve arm is 0.622):
     zero curve                              0.543
     oracle direction x constant magnitude   0.436
     copy ONE random sibling from the pub    0.426
     copy the mean of all siblings           0.345
     ORACLE own quadratic (2-coef ceiling)   0.157
   Split by what the sibling is:
     sibling with a DIFFERENT extractant     copy-1 0.402   copy-mean 0.367  (143 cells)
     sibling with the SAME extractant        copy-1 0.342   copy-mean 0.307  (218 cells)
     same extractant, ANY publication        copy-1 0.348   copy-mean 0.316  (228 cells)
   Knowing the same ligand from a DIFFERENT paper (0.348) is worth as much as knowing it
   from the SAME paper (0.342): the anchor's value is extractant identity, not the
   publication.  Note also that BP forbids this arm by construction -- BP drops every
   training cell from the held-out cell's publication precisely because deployment means
   a lab you have no data from.
